# TikTok: «7 ШІ-скілів, які роблять сайт за тебе»

Формат: вертикальне відео 9:16, 75–90 секунд, говорить одна людина в кадрі + вставки екрана.
Мова: українська. Темп: швидкий, без пауз; кожен скіл — 8–10 секунд.

---

## 0:00–0:05 — Хук

**У кадрі:** ти дивишся в камеру, за спиною на екрані відкритий готовий лендинг магазину окулярів.
**Текст на екрані:** `Сайт з 17 фото з телефона. Без дизайнера.`

> Я дав штучному інтелекту 17 фото окулярів з телефона — і він зібрав лендинг магазину. Ось 7 скілів, які це роблять.

## 0:05–0:12 — Що таке скіл

**У кадрі:** папка `.claude/skills` з підпапками.
**Текст на екрані:** `Скіл = інструкція для ШІ`

> Скіл — це набір інструкцій для ШІ-агента, наприклад Claude Code. Ставиш один раз, і він працює за правилами профі, а не «як вийде».

## 0:12–0:22 — 1. Taste Skill

**У кадрі:** скрол лендингу OpticStor: великий кадр з оправою, жовтий блок, форма замовлення.
**Текст на екрані:** `Taste Skill — сайт з нуля`

> Перший — Taste Skill. Він сам визначає, який у тебе бізнес, підбирає кольори, шрифти й макет, а потім перевіряє сторінку в браузері на телефоні й ноутбуці. Цей лендинг — його робота.

## 0:22–0:31 — 2. designlang / Design Extract

**У кадрі:** чужий сайт → таблиця кольорів і шрифтів.
**Текст на екрані:** `Design Extract — вкрасти стиль (легально)`

> Другий — Design Extract. Даєш посилання на сайт, який подобається, і отримуєш його кольори, шрифти й відступи готовими файлами. Ще й перевіряє, чи читається текст.

## 0:31–0:39 — 3. React Bits

**У кадрі:** анімований заголовок, що розсипається на літери.
**Текст на екрані:** `React Bits — 200+ анімованих блоків`

> Третій — React Bits. Це не скіл, а бібліотека: понад двісті готових анімованих компонентів для React. Безкоштовно.

## 0:39–0:47 — 4. GSAP Skills

**У кадрі:** блоки плавно з'являються під час прокрутки.
**Текст на екрані:** `GSAP — анімації без гальм`

> Четвертий — офіційні скіли GSAP. Вчать ШІ писати анімації правильно, щоб сайт не гальмував. А всі плагіни GSAP тепер безкоштовні.

## 0:47–0:55 — 5. Playwright CLI

**У кадрі:** браузер сам клікає кнопки й робить скриншоти.
**Текст на екрані:** `Playwright CLI — ШІ тестує сайт`

> П'ятий — Playwright CLI від Microsoft. ШІ сам відкриває браузер, клікає, заповнює форми й робить скриншоти. Ти не перевіряєш руками.

## 0:55–1:04 — 6. Impeccable

**У кадрі:** команда `/impeccable critique` і список зауважень.
**Текст на екрані:** `Impeccable — критик дизайну`

> Шостий — Impeccable. Команди «розкритикуй», «зроби яскравіше», «зроби спокійніше». І він ловить типовий «ШІ-дизайн», який усі вже впізнають.

## 1:04–1:10 — 7. Transitions

**У кадрі:** плавний перехід між двома екранами.
**Текст на екрані:** `Transitions — плавні переходи`

> Сьомий — Transitions Skill, для плавних переходів між сторінками.

## 1:10–1:20 — Висновок і заклик

**У кадрі:** знову ти в камеру.
**Текст на екрані:** `Збережи, щоб не загубити`

> Головне — не ставити все одразу. Для сайту з нуля бери Taste Skill, для доводки — Impeccable. Збережи відео і напиши в коментарях «список» — скину всі посилання.

## Що зняти заздалегідь

1. Запис екрана: прокрутка лендингу OpticStor (`landing/index.html`) на телефоні й ноутбуці.
2. Запис екрана: папка `.claude/skills` у репозиторії.
3. По 3–5 секунд демо кожного інструмента з його сторінки на GitHub (у README є гіфки).
4. Свій план «говорю в камеру» для хука й фіналу.

## Якщо хочеш серію замість одного відео

Розбий на 7 коротких відео по 20–30 секунд: хук «цей ШІ-скіл робить X», показ, один факт, заклик підписатися на наступну частину. Хук і фінал з цього сценарію беруться без змін.
